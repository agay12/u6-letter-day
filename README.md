One letter, A to Z, standing for the word that describes the day - a judge reads the word behind it.
The program writes it to `/output/entry.txt`, byte-identical on every run.

## Run it

```sh
node main.ts          # writes entry.txt to $MAKEFUN_OUTPUT_DIR or /output
```
